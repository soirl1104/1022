試卷全題目逐步互動詳解

完整收錄計算題 1~8 題及填充題 1~5 題的推導過程、滿分答題關鍵與觀念剖析。

計算題 1 得分 10 / 10

二次函數開口方向、頂點坐標、對稱軸及最大(小)值

y = -2x² + 4x + 1

• a = -2 < 0 ➔ 開口向下，有最大值

• 對稱軸：x = -b/(2a) = -4/(-4) = 1

• 頂點 y：-2(1)² + 4(1) + 1 = 3 ➔ 頂點為 (1, 3)

• 當 x = 1 時，有最大值 3

計算題 2 得分 10 / 10

二次函數圖形與 x 軸的相交情形

(1) x² - 3x + 5  |  (2) -x² + 6x - 9

• (1) 判別式 D = (-3)² - 4(1)(5) = 9 - 20 = -11 < 0 ➔ 沒有交點

• (2) 判別式 D = 6² - 4(-1)(-9) = 36 - 36 = 0 ➔ 相交一點 (相切)

計算題 3 得分 10 / 10

求絕對值不等式 |x + 3| ≤ 2 的解

-2 ≤ x + 3 ≤ 2

• 展開絕對值：距離中心 -3 不超過 2 單位

• 全式減 3 得：-5 ≤ x ≤ -1

• 幾何意義：在數線上介於 -5 與 -1 之間的閉區間

計算題 4 得分 10 / 10

求不等式 |2x - 5| > 3 的解

2x - 5 > 3 或 2x - 5 < -3

• (1) 2x - 5 > 3 ➔ 2x > 8 ➔ x > 4

• (2) 2x - 5 < -3 ➔ 2x < 2 ➔ x < 1

• 解為：x < 1 或 x > 4

計算題 5 得分 10 / 10

已知三頂點與重心 G(3, -1)，求 a, b

A(a, -5), B(3, b), C(4, -3)

• 重心 x 坐標：(a + 3 + 4)/3 = 3 ➔ 7 + a = 9 ➔ a = 2

• 重心 y 坐標：(-5 + b - 3)/3 = -1 ➔ -8 + b = -3 ➔ b = 5

• 答：a = 2, b = 5

計算題 6 實得 7 / 10 (扣 3 分)

直徑兩端點 A(-3, 2), B(0, 6)，求圓心與直徑長

圓心 (-3/2, 4)  |  直徑長 d = 5

• (1) 圓心坐標 (中點)：((-3+0)/2, (2+6)/2) = (-3/2, 4) (正確)

• (2) 直徑長：√[(0 - (-3))² + (6 - 2)²] = √(9 + 16) = 5

⚠ 叮嚀：試卷中漏寫了小題 (2) 直徑長，因此被扣 3 分！

計算題 7 得分 10 / 10

解一元二次不等式：2x² + 5x - 3 < 0

(2x - 1)(x + 3) < 0

• 十字交乘因式分解：(2x - 1)(x + 3) < 0

• 方程式之兩根為 x = 1/2 與 x = -3

• 開口向上且小於 0 ➔ 取兩根之間：-3 < x < 1/2

計算題 8 得分 10 / 10

平行四邊形 ABCD，求頂點 B 坐標

A(3, 4), C(-1, -2), D(2, 5)

• 對角線 AC 中點等於 BD 中點 ➔ A + C = B + D

• B = A + C - D

• B_x = 3 + (-1) - 2 = 0；B_y = 4 + (-2) - 5 = -3

• 答：B(0, -3)

填充題 1~5 全覽 得分 20 / 20

五道填充題精確計算總覽

填充題全數答對滿分

1. 因式分解 x² - 10x + 24 = (x - 6)(x - 4)

2. f(2) + f(-1) = 11 + 5 = 16

3. P(b - a, a³b) 坐標正負為 (+, -) ➔ 第四象限

4. 拋物線平移後為 f(x) = (x - 5)² - 4

5. A(-2, 5) 距離 a = |5| = 5, b = |-2| = 2
